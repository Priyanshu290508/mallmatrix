# MallMatrix 🏢⚡

MallMatrix is a modern, responsive web application for mall inventory orchestration, multi-tenant POS telemetry tracking, automated stock replenishments, and an integrated **M365 Copilot AI Assistant**.

---

## ✨ Features

- **Autonomous Orchestrator Summary**: Real-time mesh telemetry monitoring across 48 integrated retail tenant stores.
- **KPI Dashboards**: Live tracking for Gross Revenue, Stock-Out alerts, and Lease Receivables.
- **Dynamic Sales Trend Velocity**: Hourly retail transaction velocity graphing with peak conversion analysis.
- **Sub-Agent Ecosystem**: Modules for Inventory, POS Sales, Tenant Directory, Shift Roster, and Automated Reordering.
- **M365 Copilot AI Assistant**:
  - Continuous 3D twisted ribbon logo emblem.
  - Natural language prompts for automated mall management.
  - Action cards for analyzing data trends, drafting proposals, and summarizing audit documents.
  - Fixed-corner Copilot action trigger on the Dashboard.
- **Theme**: "Violet Pulse" design system with deep navy, electric violet, and ocean cyan accents.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Priyanshu290508/mallmatrix.git

# Navigate into the project folder
cd mallmatrix

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
